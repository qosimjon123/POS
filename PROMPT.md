# Restro POS — контекст для ИИ / разработчиков

## Стек (не выдумывать лишнего)

- **UI:** Vue 3 + **Quasar 2** (`quasar`, `@quasar/extras`)
- **Состояние / маршруты / i18n:** Pinia, Vue Router, vue-i18n
- **HTTP:** Axios
- **PWA:** Workbox (`workbox-*`), `register-service-worker`
- **Сборка:** Vite (`@quasar/app-vite`), TypeScript, ESLint, Prettier

## UI до кастомного CSS

Перед любыми правками внешнего вида: **сначала** проверить документацию Quasar (компоненты, `QBtn`, layout, таблицы, формы, диалоги, нотификации), **тему и CSS-переменные Quasar** (`quasar.variables.scss` / dark mode). Кастомный CSS — только если примитивов Quasar не хватает; не дублировать то, что уже даёт библиотека.

## Визуальный язык

- **База:** монохром — чёрный / белый / серые оттенки (как плотный desktop-интерфейс).
- **Акценты:** красный (и при необходимости один дополнительный акцент) — **уведомления, ошибки, предупреждения, критичные действия и важные состояния.**
- **Референс по ощущению:** desktop **ERPNext** — плотная сетка, чёткая иерархия, списки/таблицы/формы, боковая навигация, минимум «декора», максимум ясности и скорости работы с данными.
